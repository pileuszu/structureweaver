# UI fonts

The application embeds unmodified Pretendard Regular and SemiBold OTF files for
consistent Korean and Latin interface text without requiring font installation.
The fonts' version metadata is `Version 1.309;Glyphs 3.2 (3225)`.

Source project: https://github.com/orioncactus/pretendard

The copies in this repository came from the locally installed Pretendard files.
Copyright notices and the SIL Open Font License 1.1 are included in `OFL.txt`.
The macOS packaging script also includes this notice in the application bundle.
The document analysis image renderer retains its separate font configuration.
